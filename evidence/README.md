# Execution evidence checklist

The assignment asks each student to execute every task and include screenshots.
This project was prepared without a usable Python interpreter in the current workspace, so no execution screenshots are represented as completed evidence.

After installing Python 3.9 or later, from this project folder:

1. Run each command listed in the root README.
2. Save a terminal screenshot showing the command and result under the matching Task folder, for example Task03/output_screenshot.png.
3. Save generated reports under that task's output folder.
4. Re-run Task06 after observing that its error log includes the intentionally missing department_it.txt.
5. Add your own observations and any differences from the expected results to the report before submitting.
